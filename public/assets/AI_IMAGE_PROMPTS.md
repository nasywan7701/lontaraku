## 🛠️ Langkah Konversi Gambar ke Format WebP

Setelah gambar di-generate dari AI tool:
1. Simpan gambar asli (PNG/JPG).
2. Resize ke dimensi target:
   - Ornamen Hero: Lebar `800px` (atau `1200px`).
   - Kosa Kata: `480x440px` (resolusi retina untuk wadah `240x220px`).
3. Konversi ke WebP menggunakan perintah cwebp atau Node/Sharp:
   ```bash
   cwebp -q 85 input.png -o output.webp
   ```
4. Letakkan file hasil pada `public/assets/vocabulary/[nama].webp` atau `public/assets/ornaments/[nama].webp`.
